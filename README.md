# IoT-Based-Smart-LED-Matrix-Display-System

An ESP32-powered smart LED matrix display that enables real-time information visualization and wireless control using Wi-Fi.

---

## Features

- Display scrolling text
- Smartphone/Web control
- Brightness adjustment
- Multiple display animations
- Real-time message updates
- Wi-Fi connectivity
- Modular firmware
- Easy expansion for IoT applications

---

## Hardware Used

- ESP32 Development Board
- WS2812B LED Matrix (8×8)
- USB Power Supply
- Jumper Wires

---

## Software Used

- Arduino IDE
- FastLED Library
- ESPAsyncWebServer
- HTML
- CSS
- JavaScript

---

## Project Architecture

Phone/PC
↓

Wi-Fi

↓

ESP32

↓

WS2812B LED Matrix

---

## Working

1. ESP32 creates a Wi-Fi web server.
2. User connects through a browser.
3. Messages are sent wirelessly.
4. ESP32 processes the request.
5. LED Matrix displays the information.
